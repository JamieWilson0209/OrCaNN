infer output: cached probability maps

  infer_outputs_<run key>/
      <recording>/   prob.npy  max_projection.npy  meta.json  prob_overlay.png

The model that ran is part of the key recorded in each meta.json -- by its
content, so the same weights promoted under a second name reuse these maps.
Promoting a different model leaves these reading as out of date and they are
recomputed; it does not overwrite them silently and does not leave them looking
current.

This is the expensive stage and its output does not depend on any knob tuned
below it, so a run whose inference settings are unchanged finds this store
whatever its own run key is, and computes nothing.

meta.json is written last and is what marks a recording done: a run killed
partway leaves a prob.npy no later run will read.

Written by: infer (GPU).   Read by: segment.

This folder ships empty to preserve the directory structure so the tree survives a browser
upload to GitHub. Contents stay local and are not committed; delete this placeholder
once the folder holds real files.
